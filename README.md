# 知行工坊（Zhixing Hub）

以**能力**为公共语言、连接高校培养、学生成长与企业用人的产教融合平台。内核是一套能力语义空间：把学校的课程知识、学生的经历证据、企业的岗位要求翻译到同一坐标系，使培养、认证、匹配成为可计算、可审计的过程。

## 阅读建议

- 全员先读 **00 → 01**，建立公共语言；
- 按角色再读对应专项文档；
- **02 是所有"结论为何如此"问题的最终依据**——等级、匹配度、排序的任何疑问以 02 的规则为准；
- 产品与研发按 **04 → 07 / 08 → 09 → 10 → 11** 依次建立产品、组织与过程、页面、界面和技术实现视图；
- 各文档间以"《XX》第 N 节"交叉引用，不重复展开；同一规则只在一处定义。

四层边界：**00–08 定业务规则与设计纪律** → **09 定信息架构**（有哪些页面、每页有什么、谁能看见）→ **10 定视觉与交互形态** → **11 定技术实现**。09–11 均不得改写 00–08；冲突时以被引业务条款为准。
