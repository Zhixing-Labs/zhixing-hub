# 05 治理与合规章程

**文档体系 v1.0 · 治理规则 · 读者：平台运营、委员会成员、合作校企对接人**

本章程规定各类资产的权属、变更流程与节奏，以及数据合规义务。总则：**冻结的内核 + 可生长的外层 + 版本化的一切**。

---

## 1. 治理主体

| 主体 | 构成 | 职责 |
|------|------|------|
| 平台框架委员会 | 平台发起，含校企代表 | 内核（18 条 + 分级模板 + 关系集）与算法规则的变更评审；年度窗口制 |
| 联合评审委员会 | 校企工程师 + 平台守门人 | 词表准入审查、挂靠争议裁决、岗位族标准与字典过审；例会制 |
| 判例库 | 联合评审委员会维护 | 裁决记录沉淀，同类争议直接引用，降低仲裁成本 |

## 3. 版本与迁移

### 3.1 条目变更迁移规则

| 条目变更 | 迁移规则 |
|---------|---------|
| 新增 | 无迁移 |
| 拆分 | 旧声明按映射表迁移至新条目，强度档降一档 |
| 合并 | 声明归并，等级取最高；归并后强度档取被保留的最高等级声明的强度档，同等级多条声明取其中较强档 |
| 废弃 | 声明冻结：保留展示，退出匹配 |
| 时效类型变更（快变 / 稳定 / 累积增值之间改判） | 计入词表版本并触发全量重算；按新类型自 issued_at 重算强度档（《02》第 7 节），稳定化改判可使既降的强度档回升，发布说明须写明"结论可能回升" |

每次发布附迁移表，全体画像按"证据不可变、解释可重算"重算；岗位模型引用的条目变更时，平台通知企业确认增量。

### 3.2 版本向量与重算义务

每条结论携带七元版本号（词表, 含金量字典, 观察聚合规则, 门槛表, 时效参数, 抽取模板, 星级规则）。任一资产发布新版本即触发全量重算，**默认随下一个重算槽（每周一 02:00）生效，发布方可加开即时槽**；重算机制与确定性要求见[《02 证据与等级判定规范》](02-证据与等级判定规范.md)第 12 节。**发布方的义务**：发布即附迁移表与生效日期；重算槽内对外结论只读、展示旧版本向量结论并标注"校准中"（《04》第 4.3 节），槽结束一次性切换——**不建新旧代次并行对外的双读体系（定案）**；在招岗位发布按其开放时快照的模型与标准版本对照，不受重算槽影响（《04》第 4.4.1 节）。

## 4. 企业合作分层（不进平台，定案）

平台不设企业分级名录、战略合作档及任何企业档位、评级与升降机制：企业分层合作（战略协议、保底供给、重点合作等）属平台运营方的战略决策，一律线下处理，不进产品、不进计量、不进治理流程。含金量字典因此只含竞赛 / 论文 / 认证三部（《02》第 4.1 节）；企业性质标签仅为决策场景的展示信息（《07》第 2.3 节），不参与任何证据定档。

## 5. 数据合规

- **授权**：证据采集需学生**逐项授权**；企业对画像明细与证据链的查看以学生授权为闸（求职可见开关 / 报名申请 / 人才库授权，《04》第 4.4 节），候选列表汇总层（覆盖率与同侪分布概览）为平台基础功能默认展示、不可退出；进入企业人才库需学生授权且可随时退出；
- **归属**：档案归属学生，可导出带走（v1 导出形态 = 结构化 JSON + 证书 PDF 清单，不做版式简历——简历导出另走《04》第 4.7 节大模型通道）；
- **可审计**：任何对外输出的结论必须可展开为证据链（证据、规则、版本）；
- **异议**：学生可对声明提出异议，进入审核队列（《02》第 11 节）按双通道复核，成立的以**追加记录**方式修正——原始记录永不修改，作废用冲销记录表达（冲销与替代声明的封闭操作见《02》第 11.2 节）；异议集中受理窗口为项目结束后 14 天评价期（《08》第 2 节），其余时间照常受理；
- **匿名纪律**：同侪分布与个体参照系一律匿名聚合；相似前辈仅呈现匿名化路径（成长轨迹与去向可见、身份信息不展示），不设可识别形态（《04》第 4.6 节）；学生每日反馈对企业端去名并防识别加固（《08》第 6.8 节）；证据链中的评价人实名可见**不属**匿名纪律范围——签字负责是信源公信力的一部分（《04》第 4.3 节）；
- **高敏数据**：困难群体标记仅学校侧录入，不进画像、推荐与筛选视图，加密存储、读取留审计（《07》第 4.4 节）；
- **注销与证书**：注销删除全部个人档案与数据，已颁发证书及其公共验证永久有效（《07》第 5.5 节）。

## 6. 治理红线

1. 接入任何新岗位族、新学校、新企业，不得修改内核；
2. 任何影响结论的规则与字典变更，必须先落为版本化资产再生效，禁止运行时临时判定；
3. 大模型产出（字典起草、抽取、对齐）必须经人工确认后方可影响结论；
4. 对学生 / 企业个案的全部人工裁决走统一审核队列（《04》第 4.8 节，含口径界定），不设体系外特批通道；治理类事项（词表、字典、标准、算法规则、题库与资源入库）走本章程治理流程。
